How metrics are calculated

Local and cloud shares use successful requests. Generation speed uses the provider’s generation duration. P95 uses nearest rank and needs at least 20 measured latencies. Token totals count known provider values. Conversations recorded before the inference ledger are excluded.

API charges exclude device electricity and hardware. Savings estimates require a documented cloud baseline. Reply feedback measures perceived helpfulness.
